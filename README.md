# VoterLens

VoterLens is a full-stack political accountability and civic engagement platform that enables citizens to discuss governance, report civic issues, participate in polls, and evaluate political leaders across India's administrative hierarchy—from Gram Panchayats to Members of Parliament.

## Features

- User Authentication (Firebase Authentication)
- Anonymous & Public User Profiles
- Political Discussion Feed
- Civic Issue Reporting
- Political Leader Profiles
- Political Party Pages
- Polling System
- AI-Assisted Content Moderation
- Reputation System
- Admin Dashboard
- Location-based Discussions
- Analytics Dashboard

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/VoterLens.git
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and add your Firebase configuration and any required API keys.

Run the application:

```bash
npm run dev
```

Open:

```
http://localhost:3000

## AI Features

VoterLens uses the Google Gemini API to provide:

- Sentiment Analysis
- Fake News Detection
- Content Moderation
- AI-generated Summaries
```
